# PCP para Confecção Jeans

Sistema web de Planejamento e Controle da Produção desenvolvido para indústrias de confecção.

## Objetivo

Gerenciar produtos, operações, máquinas, costureiros, roteiros, ordens de produção, apontamentos, carga-máquina, eficiência e gargalos produtivos.

## Tecnologias

- HTML
- CSS
- JavaScript
- Node.js
- Express
- PostgreSQL
- Git e GitHub

## Estrutura inicial

- `backend`: API e regras de negócio em JavaScript;
- `frontend`: interface do sistema, que será criada nas próximas etapas.

## Situação do projeto

Projeto em desenvolvimento. A estrutura inicial do backend e a primeira rota da API já estão funcionando.
